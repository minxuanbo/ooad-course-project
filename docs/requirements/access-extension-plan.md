## 范围与一致性

部门角色owner在操作者子树内，目标也在操作者子树及owner子树内；实际API、人员本人/同级/上级保护、完整计划权限子集同时满足。待接入权限参与计划子集，不先过滤为空集。管理员互管和至少一名独立完整K维护者不变。

候选、角色列表均数据库先过滤后分页计数；局部读取仅部门角色，不返回全公司角色或人数。锁后重读原集合，仅校验新增/删除差集，不可改现有项锁定保留。人员调动同事务撤下不再适用的部门角色，调回不恢复；逐请求鉴权再查当前归属，部门有所属角色拒绝删除。

无新增委托、审批、角色继承、自动岗位推权、模拟业务Controller或启动自动重授。全新库首次SQL保留12表，新增两条核心外键；旧库/卷/日志及原件保留。既有部署库不自动升级，后续发布前另核对兼容数据。
