# 离线原型使用说明

打开 [06-界面原型.html](06-界面原型.html)，将原型权限清单.js、原型应用鉴权.js、原型管理权限.js 保持在同目录。无需服务、不调用真实后端；虚构数据保存在页面内存，刷新重置。

## 身份与角色

提供系统管理员、普通员工、公司领导、部长、副部长、项目经理、项目副经理、项目总工程师示例身份。
仅使用系统管理员、公司领导、部门经理、项目经理、普通员工五类角色。部长／副部长共用部门经理，三个项目管理岗位共用项目经理；不设审计员。

## 建议演示

1. 系统管理员登录，导航依次为我的应用、工作台、组织管理、用户与授权、角色与权限、业务系统、鉴权日志。
2. 组织管理查看“公司—部门—操作”，无上级部门／上级公司列。
3. 人员页选择“分配角色与管理范围”。上半区“① 分配角色”，下半区“② 设置管理范围”。
4. 点击“＋ 添加范围”，选择上方已分配的角色。公司范围只选公司；部门范围选公司和该公司的部门；全平台仅适用于系统管理员且无需组织。
5. 同一角色可添加多条范围。切换范围清除无关字段，撤销角色移除其范围。点击“保存全部更改”生效，取消不保存。
6. 角色页面分别查看／配置“业务功能权限”和“管理操作权限”；修改角色操作会影响所有持有者，不修改员工范围。
7. 切换部长、副部长或项目岗位身份，检查组织和人员只在其管理范围内，不显示全局鉴权日志。
8. 切换普通员工，查看本人应用和功能按钮；操作只演示鉴权，不执行真实业务。

角色决定操作，范围决定可管理的组织。角色无范围时业务功能仍生效，但没有后台管理权。外部业务系统内部数据权限不在此范围控制内。

## 验证边界

脚本逻辑测试检查共享布局、范围过滤、联动字段和草稿提交。未进行完整浏览器视觉和端到端验收；可在浏览器人工检查滚动、焦点、弹窗和窄屏效果。原型不代表生产认证或真实员工数据。
