# 离线界面原型使用说明

直接用浏览器打开 `06-界面原型.html`，保留同目录的 `原型权限清单.js` 和 `原型应用鉴权.js`。无需启动数据库、Spring Boot、Vue 或其他服务，无需输入真实账号密码。

原型只提供离线演示，不发起后台请求。人员为虚构数据，功能目录与初始角色权限来自课程 Excel 清单，包含 18 个系统、2521 项操作权限。所有修改与日志仅保存在当前页面内存，刷新浏览器或点击“重置演示”恢复初始数据。不同窗口之间不共享授权状态。

## 员工演示

1. 选择“普通员工 · 示例员工甲”登录。
2. “我的应用”仅显示有权限的系统；无权限系统隐藏，不能进入或查看其功能目录。没有任何授权时显示“暂无可用应用”。登录时只有一个可用系统则自动进入。
3. 进入系统，选择功能模块，查看功能点对应的查看、新增、编辑、删除、审批、导出、配置等操作按钮。
4. 有权限按钮可点击，按当前演示授权模拟鉴权并记录日志；无权限按钮置灰不可点击。不执行实际业务增删改或审批。
5. 点击“模拟撤回全部权限”演示撤权；当前系统不再有权限时立即返回“我的应用”。可通过“恢复演示权限”恢复。

普通员工不显示鉴权日志入口，也不能访问日志页面，但其操作仍产生本地演示日志。

## 管理员演示

退出员工身份并选择“系统管理员”，可以使用用户授权、角色权限配置、公司部门筛选、电话查询、分页与离职交接等原型功能。

在“用户与授权”修改示例员工甲的角色，或在“角色与权限”修改对应角色的操作权限，再切换回员工身份验证。切换身份保留授权变更和日志，员工权限取其所有角色的并集。

仅管理员能查看“鉴权日志”，其中包含员工和管理员在本次演示中的系统准入、操作权限检查结果。灰色按钮不可点击，因此不会生成操作日志。重置演示会清空全部日志。

## 建议验收

- 普通员工登录后没有日志入口，也看不到无权限的财务管理系统。
- OA → 公文管理 → 收文登记与流转：查看可用，编辑等未授权操作置灰。
- 点击查看后，切换管理员，可以在日志中找到该员工的操作记录。
- 管理员调整角色权限后切回员工，系统列表与按钮随新授权改变。
- 在应用内模拟全部撤权，立即返回空应用列表；恢复后可再次进入。
- 离职交接完成并停用示例员工后，该员工不能再次登录；重置可恢复演示。

这只是课程交互原型，不构成真实认证或安全隔离；在原型中的操作不会修改正式项目数据库。
