核对日期：2026-10-23。本文根据当前源码、DDL 与本次执行结果编写，不沿用早期“本机服务正在运行”或“尚未推送”的临时状态。

## 已实现范围

Spring Boot + JdbcTemplate + MySQL、Vue 前后端分离；15 张表支持组织、目录、RBAC0 授权、会话、日志与离职交接。
我的应用只显示有效授权系统；准入后可浏览模块/功能目录，操作按钮调用真实鉴权而不执行外部业务 CRUD。
有效权限要求用户、角色、应用、模块、功能、动作与权限条目均有效；每次请求重查，无权限缓存。
管理员可筛选人员、替换用户角色与角色权限、查看日志、办理交接；完成交接原子撤权、停用并撤销会话。
前端每 3 秒及重新聚焦刷新，显示延迟不能当作服务端继续放行。离线原型使用虚构人员及内存授权，不连接数据库。

## 已知限制与设计差距

- 未知路由与错误 HTTP 方法仍被通用处理映射为 500；设计期望 404/405 尚未实现，测试明确记录现状。
- 没有用户/角色/部门/系统完整 CRUD、密码重置、OAuth/OIDC、可信服务间认证或实际外部业务接入。
- 管理身份仍按系统管理员角色判断，未细分管理操作或部门范围；无最后管理员保护与角色编辑版本冲突检测。
- 部门复合外键保证同公司父子，但不保证无环；负责人外键只检查用户存在，持续任职资格维护未实现。
- 初始化负责人的姓名无法匹配则保留空值；组织映射失败或歧义时报错，不能靠猜测填充。
- 100% 结构覆盖率不等于所有故障/输入组合覆盖，不替代压力、渗透、并发和恢复测试。
