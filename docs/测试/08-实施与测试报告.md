# V2 实施与测试报告

日期：2026-10-16。范围：按新版界面原型、API 与数据库设计修改正式 Spring Boot + Vue 项目；保留独立离线原型。未提交或推送 Git。

## 1. 已实现内容

- 我的应用只显示有有效权限的系统；首次登录只有一个系统时自动校验进入，多系统由用户选择。
- 系统 → 模块 → 功能点 → 操作按钮。无权限按钮置灰禁用；点击有权限按钮调用真实后端鉴权，允许或拒绝均记录日志，不执行外部业务数据读写。
- 系统准入、模块目录和功能目录分别检查当前权限；无法通过直接 URL 或伪造请求读取无权系统目录。功能目录还检查模块所属系统。
- 每次操作读取最新授权；页面每 3 秒与重新聚焦时同步。撤权后新请求立即拒绝，系统整体失权时清空目录并退回应用列表；网络失败不继续使用旧目录。页面显示可能有轮询间隔延迟，不等于服务端允许操作。
- 员工看不到日志或管理导航，直接调用管理接口仍拒绝；管理员可以查看员工产生的鉴权日志。日志 limit 限制为 1–500。
- 保留用户公司/部门筛选、电话展示、角色授权及离职交接。更新相关查询以适配新数据库。

主要代码：System.vue、Portal.vue、Management.vue、App.vue、api.js、AuthService.java、ApiController.java、ApiExceptionHandler.java、DataInitializer.java、SchemaGuard.java 与 schema.sql。

## 2. 数据库实施与数据保留

现行 MySQL 共 15 表。新增 companies/modules/features/actions；用户公司从部门关联获得，权限只引用功能点和动作，不重复保存可推导的系统与功能文字。关系表、唯一约束与外键保持授权事实完整，未存储用户有效权限快照。

迁移脚本 scripts/normalize_mysql.py 默认只读预检，显式 --apply 才执行。执行前需停止后端及其他写入连接，先完整备份，再扩表、回填、核对并移除旧字段。对保留字段做行数与 SHA-256 比较，对每名用户的有效权限代码和系统集合逐项核对；权限 ID/code 不变。

本机业务库迁移完成，包含 10 个公司、111 个部门、10001 个用户、115 个模块、359 个功能点、2521 条权限、5 个角色、10240 条用户角色关系及 3916 条角色权限关系。迁移核对通过；随后浏览器登录和操作会正常新增会话及审计记录。

私有备份和核对报告（含敏感数据，不提交 Git）：

- `.local/mysql/backups/rbac-before-normalize-20261015T140304122071Z.sql`
- `.local/mysql/backups/rbac-normalize-20261015T140304122071Z.json`

组织数据处理：原 9 个跨公司父子关联调整为各公司独立根节点；总公司负责人无法精确匹配本部门员工，保留 NULL，未猜测关联。原始内容在完整备份中保留。操作字典兼容原有“查看本人”“编辑本人”和 view，不将名称误当作行级权限实现。

MySQL DDL 隐式提交，迁移不能整体事务回滚。测试库首次试迁移遇到 MySQL 自增列 CHECK 限制及复合外键建键顺序问题，修正脚本并核对剩余 DDL 后完成测试库升级；该次中断报告不作为完整成功证明。之后业务库完整迁移通过核对，全新库也通过初始化测试。出现部分迁移时脚本拒绝盲目重试，应检查报告或人工恢复。

## 4. 浏览器检查

使用普通员工登录确认：只显示已授权应用；进入 OA 模块与功能后查看按钮可用，其余未授权按钮禁用；点击查看提示真实鉴权通过。员工直接访问日志路由被退回应用页。浏览器操作产生正常审计记录，不改动角色授权。管理员读取员工日志和撤销管理权限后的拒绝已由后端集成测试覆盖，本轮未完成管理员日志页面的独立浏览器验收。

## 5. 边界与待办

- 本次是功能级 RBAC0 鉴权演示，不是接入所有业务系统；没有真实新增、编辑、审批、导出业务操作，也没有行级“本人数据”过滤。
- 无新增用户 CRUD、角色创建、部门维护、通用系统注册、OAuth/OIDC 或服务间认证。结构化业务流程沿用现有 Java 框架承载方式，未引入领域对象继承或函数式业务流水线。
- 部门循环关系在迁移预检中验证；未来提供组织维护接口时必须检查祖先链及负责人资格。当前数据库复合外键限制跨公司父子关系，但不能单独防止所有循环。
- 历史 SQLite 导入已调整为冻结 V1 DDL 后再升 V2，仅做语法检查，本轮没有再次端到端执行该历史路径。
- 未进行负载、渗透及全浏览器兼容测试；多管理员授权并发编辑仍无版本冲突检测。
