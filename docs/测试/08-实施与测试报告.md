# 实施与测试报告

2026-10-25，V4 角色管理操作与员工角色范围版本。当前规则以五份课程设计文档为准；两份 adoc 只描述设计，本文件记录执行结果。

## 实施内容

使用原有五类角色，角色定义业务及管理操作，范围绑定每个员工的具体角色分配。部长／副部长映射部门经理，三个项目管理岗位映射项目经理；公司与精确部门范围、多范围兼管、全局日志仅系统管理员可见。
19 张表中 management_grants 为旧授权存档；运行时使用 role_management_permissions 与 user_role_scopes。旧管理授权接口已移除。

原型和 Vue 更新人员角色范围分区、条件组织字段、添加范围按钮、保存／取消草稿；组织表为公司—部门—操作。菜单顺序为我的应用、工作台、组织管理、用户与授权、角色与权限、业务系统、鉴权日志。前端不部署。
