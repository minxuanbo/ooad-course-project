# 管理权限改造说明

2026-10-25，V4。最终方案沿用原有五类角色，不新增独立管理角色。原型／Vue 已调整，仅后端部署。

## 主要变化

- 角色页面配置“业务功能权限”和“管理操作权限”，影响该角色所有持有者。
- 员工页面“分配角色与管理范围”只调整该人的角色及角色范围；角色决定操作，范围决定管理对象。
- 部长／副部长同用部门经理，项目经理／项目副经理／项目总工程师同用项目经理；初始岗位映射修正后可再显式配置。
- 公司范围覆盖所属全部部门，部门范围精确匹配，全平台仅用于系统管理员。无子部门递归，无审计员；全局日志仅系统管理员。
- 弹窗分区，添加范围显式按钮，按类型显示字段，统一保存草稿；组织表公司—部门—操作，菜单按应用、工作台、组织、人员、角色、系统、日志排列。

## 保留边界

管理范围只控制本平台管理接口，不自动约束外部业务系统内部数据。parent_id 和旧 management_grants 仍保留结构兼容，不代表当前支持子部门范围或员工直接管理操作授权。没有用户／角色全量 CRUD、组织移动、密码重置和 HR／OA 自动同步。

上线转换只修正没有手动角色变更记录的导入员工，保留其他手动或自定义分配；完整业务库已备份。原型模拟 DOM 测试不代替真实浏览器视觉验收。
