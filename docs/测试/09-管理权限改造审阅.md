# 权限、范围与审计功能说明

角色定义业务功能和管理操作，员工该角色的范围定义可以管理的对象。五类角色为系统管理员、公司领导、部门经理、项目经理、普通员工；部长／副部长使用部门经理，项目经理／项目副经理／项目总工程师使用项目经理。不设独立审计员。

人员授权弹窗区分角色与范围，角色可绑定多个公司／部门范围；全平台只用于系统管理员。范围保存与角色修改原子提交，撤角色级联撤范围，最后平台管理员受保护。
组织管理展示公司—部门—操作，不设置父部门。数据库部门范围只存部门 ID，不重复保存可由部门推导的公司 ID。用户名、工号和手机号经统一登录标识登记表与事务触发器跨字段唯一。

日志支持用户、系统、结果、事件、UTC 时间、归档状态筛选与游标分页。系统管理员可批量逻辑归档，记录仍可查询；登录失败、未认证与拒绝访问保留认证审计。所有接口统一 code/message/data/requestId，稳定业务错误码区分越权、会话和业务前置条件。

HTTP 绑定、业务事务、SQL 持久化、DTO 契约分别由 Controller、Service、Repository 和 DTO 层承担。基础设施组件负责初始化、数据库约束与 Excel 读取。

审阅入口：[原型](../原型/06-界面原型.html)、[API](../课程设计/03-API设计文档.md)、[数据库设计](../课程设计/04-数据库设计文档.adoc)、[详细设计](../课程设计/05-详细设计文档.adoc)、[测试报告](08-实施与测试报告.md)、[JaCoCo](../../reports/README.md)。

管理范围只约束本平台管理操作，不自动约束外部业务数据。逻辑归档不等同于外部冷存储；不提供用户全量 CRUD、组织移动、密码重置、HR/OA 自动同步。前端只交付源码和原型，不部署。
