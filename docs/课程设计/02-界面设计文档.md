# 界面设计文档

版本 4.0 · 2026-10-25。配套 [API 设计](03-API设计文档.md) 和 [离线原型](../原型/06-界面原型.html)。

## 导航与布局

菜单依次为：**我的应用 → 工作台 → 组织管理 → 用户与授权 → 角色与权限 → 业务系统 → 鉴权日志**。组织、人员、授权相邻，日志置于最后。全部页面共用侧栏、顶栏及内容容器；应用功能页保持我的应用高亮。

| 页面 | 路由 | 入口权限与用途 |
| --- | --- | --- |
| 我的应用 | /portal | 登录；仅列本人有效授权应用 |
| 工作台 | /dashboard | user.read；范围内统计 |
| 组织管理 | /organizations | org.read；公司—部门—操作三列 |
| 用户与授权 | /users | user.read；范围内查询、分页及授权操作 |
| 角色与权限 | /roles | role.read；查看角色，按权限配置业务／管理操作 |
| 业务系统 | /apps | app.read；共享系统目录 |
| 鉴权日志 | /logs | 系统管理员 GLOBAL audit.read；全平台日志 |

无权限菜单不展示；路由及 API 独立检查。普通员工只显示我的应用。公司领导、部门经理、项目经理的菜单随角色管理操作和员工范围决定，不设置审计员身份。

## 用户角色和范围弹窗

“分配角色与管理范围”修改一名员工，分为两个有标题和边框的区域：

1. **① 分配角色**：勾选现有角色，决定员工拥有哪些角色。修改某角色的操作定义应进入角色页面。
2. **② 设置管理范围**：点击“＋ 添加范围”增加草稿行，从上方已选角色中选择该范围适用角色。同一角色可配置多个公司或部门范围。

| 范围类型 | 显示字段 | 含义 |
| --- | --- | --- |
| 全平台 | 不显示公司和部门 | 仅系统管理员角色可用 |
| 指定公司 | 公司 | 所选公司全部部门 |
| 指定部门／项目部 | 公司、部门 | 部门选项按公司联动，精确匹配 |

切换角色／范围时清空不适用组织字段，切换公司清空部门。取消角色时移除该角色的草稿范围。
添加、移除和角色勾选均点击“保存全部更改”才生效，关闭或取消不保存。移除“本次保存时新增”的复选框，避免隐藏提交语义。
只分配角色没有范围时，业务功能权限仍生效，该角色不产生后台管理权。权限范围不能跨角色拼接。

部长和副部长使用部门经理，项目经理／项目副经理／项目总工程师使用项目经理；范围按每人独立配置。比如同为项目经理角色，一人管第一项目部，另一人可兼管第一和第二项目部。

## 管理页面细节

组织表只显示公司、部门、操作；编码在 Vue 名称下作为辅助信息。公司管理要求 GLOBAL org.write；公司范围可新增部门，精确部门范围只能维护已有部门。默认部门经理和项目经理没有 org.write，需系统管理员在角色管理操作中显式配置。无组织移动、删除和上级部门选择。

人员页支持公司、部门、关键词组合筛选，切换公司清空部门、重置页码，每页 20 人。无结果、加载、错误均提供反馈。managementActions 控制人员操作按钮；局部管理员不能修改自己或管理账号，不能分配超出自身业务权限的角色。

系统管理员使用统一角色范围弹窗；局部管理员仅能在有权目标上分配业务角色，不能设置管理范围。撤销角色同时撤销范围，保留的角色范围不变。

角色页分别提供“业务功能权限”和“管理操作权限”。修改影响全部角色持有者，但不改变每个人的范围；均需 GLOBAL role.permissions。共享角色无公司私有副本。

离职发起／完成分别检查操作权限和范围。发起保留授权，完成统一撤角色和范围、停用账号、撤销会话、保留历史。范围外关联人员显示“范围外人员”。

## 同步、原型与验证边界

每三秒及窗口聚焦刷新 /me。派生 managementGrants 变化时卸载旧管理视图、重载数据；无当前页权限则返回我的应用。前端不构成授权安全边界。
离线原型使用虚构员工和内存状态，无需联网；刷新即重置。Vue 连接真实 API。原型脚本测试采用模拟 DOM，构建和逻辑检查不能代替真实浏览器视觉及端到端验收。
