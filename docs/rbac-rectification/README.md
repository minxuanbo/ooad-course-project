## T03 开工指令

先按[协作步骤](../../CONTRIBUTING.md)人工认领，确认 PR #18 已合入并获取最新共同基线；核对目标分支及已有工作后发送：

```text
执行 https://github.com/minxuanbo/ooad-course-project/issues/4（T03），只做组织与人员导入闭环。
先读 AGENTS.md、CONTRIBUTING.md、整改入口、原版计划 2.3—2.5、
3.3—3.5、4.1—4.4 和 5.3—5.4、复核说明及任务清单 T03，确认 T02 合入证据及最新口径。
从最新 origin/refactor/rbac-core-backend 建立独立任务分支/工作树。
复用 Excel 读取和 T02 JPA 模型，在独立整改库核对共同根、组织无环连通、
10,000 人、111 个节点及全量归属，保留来源映射；读取不得被 A1 范围标记截断。
Excel 没有工号、哈希、状态或角色分配；核对旧库来源与模型必填适配，缺项不得编造。
根节点无直属员工；核对可复用维护账号和明确归属方案交 T05，不移动原员工或按岗位提权。
明确状态转换，未知状态/归属记录异常，不默认启用或赋权，不导入旧业务目录。
验证重复导入、失败回滚或安全重试，不覆盖已调整授权；保留原库、原始 Excel 与本地资料。
交付可复现的 MySQL/JPA 导入结果和小样本核对，不新增正式 Controller 或页面。
提交本票必要文件并推送，创建 base=refactor/rbac-core-backend 的草稿 PR，
正文 Refs #4，不自行合并、关闭票或启动其他下游任务。
```

## 范围和资料维护

2026-11-07 用户更新：有效账号还须具有本权限系统有效管理操作权限才允许登录，普通员工/无管理权限拒绝；复用原登录流程和统一有效权限计算，不新增管理员属性、资格表、认证接口或令牌机制。管理请求仍逐次校验具体权限和部门范围。

鉴权日志优先复用旧最小记录及查询，相关 JDBC 迁 JPA；仅有日志权限的全局维护者可查看，部门管理员拒绝。不恢复归档、导出或完整审计，日志不加入核心 Chen ER。部门人员/组织查询仍限本部门及下级，不新增完整组织 CRUD。

补充图片要求 REST、读写声明式事务和 CloneFactory；用法来源缺失时记录未决，不能只写名称算完成。T10/T11 必须覆盖跨部门调动；针对用户的权限继续通过角色分配实现。完整边界见[原版计划](RBAC整改计划与Chen-ER图.md#11-补充依据与本次保持的边界)。

正式接口先完成对应原型/API 契约评审；前端正式开发暂缓，原型仍要做。课程受控场景由后续两票落实，不能用系统字段预留代替完成。

[旧实现资料](../legacy/README.md)仅供差异核对；旧原型不是整改原型，也未因此获得界面验收。三份原始 Excel 保留在仓库根目录。
