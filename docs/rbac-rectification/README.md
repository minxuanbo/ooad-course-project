[T01 / Issue #2](https://github.com/minxuanbo/ooad-course-project/issues/2) 没有前置阻塞，可人工认领。交付模型与授权规则核对、工程复用/替换/删除对照、证据及未决项，不写正式接口。

T01 静态核对产物已直接补入原版计划的 [2.5 模型映射](RBAC整改计划与Chen-ER图.md#25-t01-模型核对与-t02-映射提案)、[3.3 管理员保护](RBAC整改计划与Chen-ER图.md#33-t01-有效全局管理员与保护边界提案)、[4.1—4.2 替换及隔离边界](RBAC整改计划与Chen-ER图.md#41-t01-工程复用替换与删除对照)，[5.3](RBAC整改计划与Chen-ER图.md#53-t01-评审记录与未决项)记录待确认项；未冒充小组评审通过。

完成材料后由小组评审，必要结论回写执行计划并合入共同基线，再解除下游阻塞。此后 T02/T04/T06/T08/T10 可分别启动；T14/T15 仍须另行确认后续范围。

## T01 开工指令

按[协作步骤](../../CONTRIBUTING.md)从 origin/refactor/rbac-core-backend 建立 T01 工作树，在新目录打开 VS Code/Codex 后发送：

```text
执行 https://github.com/minxuanbo/ooad-course-project/issues/2（T01）。
先读 AGENTS.md、CONTRIBUTING.md、整改目录 README、原版执行计划、
检查记录复核说明（含技术纪要摘录）和任务清单的 T01 章节。
检查 Git 状态与共同基线，保护本地资料。
只完成模型、授权规则与逐块替换边界核对；交付实体关系与规则结论、
复用/替换/删除对照、最小身份衔接、调用/初始化/测试/配置/文档影响，
以及证据出处、未决项与受影响下游票。
区分检查纪要要求、用户补充和方案建议；旧资料只供差异参考。
完成后提交本票文档与验证边界并推送，创建 base=refactor/rbac-core-backend
的草稿 PR，正文 Refs #2。由小组评审结论，不自行合并、关闭票或启动下游。
```

## 范围和资料维护

有效账号通过既有身份校验可登录；无管理权限显示提示；管理请求按具体权限和部门范围校验。不增加管理员属性、独立登录资格或新的认证功能。

正式接口先完成对应原型/API 契约评审；前端正式开发暂缓，原型仍要做。课程受控场景由后续两票落实，不能用系统字段预留代替完成。

[旧实现资料](../legacy/README.md)保留供源码差异核对；原型移动后仍由现有逻辑测试读取，不是整改原型，也未因此获得界面验收。原始三份 Excel 保留在仓库根目录。

只维护本目录的执行计划与任务清单，不提交单票镜像、讨论副本、分享压缩包或发布脚本。业务代码、数据库、HTTP 和并发验证以相应任务的实际证据为准。
