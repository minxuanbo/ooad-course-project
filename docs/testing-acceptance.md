## 3. 复现入口与隔离

Java21/MySQL8.4，先安装[固定CloneFactory](../deploy/README.md#本机依赖安装)。真实数据库回归使用六个本机专库，profile与URL严格匹配；完整环境变量和默认JAR探针见[T13复现步骤](acceptance/T13.md#2-可复现步骤)。不得为了跑通测试把守卫改成业务库，或用线上演示账号替代夹具。

产品初始化命令只维护在[部署说明](../deploy/README.md#新库初始化约束)。验收探针拒绝非空库并核对实际datadir，失败不自动清库。隔离环境、原始资料与测试夹具分别标注；报告记录源提交、JDK/MySQL版本、命令、结果及限制。未来代码归类或DDD阶段须重跑受影响真实回归，不能沿用T13数字。

JaCoCo脚本和门槛见[现场说明](../deploy/现场运行JaCoCo.md)；用户确认当前不作为阻塞，配置保留。功能test通过不等于verify覆盖率达标，不通过时不得用skipTests、排除类或旧exec冒充。无Docker环境时不宣称镜像/Swarm验收。

临时日志、CSV、数据库、凭据、构建报告放忽略目录；不提交万人清单或含秘密的Surefire XML。保留原Excel、原库和历史日志。每阶段记录自动验证、代理审核、用户审核三种不同证据；代理双轴复核不代替用户/老师验收。
