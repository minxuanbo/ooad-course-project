# 文档导航

| 入口 | 用途 |

| [RBAC 整改](rbac-rectification/README.md) | 当前执行依据、检查纪要技术摘录、ER 图和完整任务清单 |

项目只维护一份执行计划和一份完整任务清单。文档不另设版本号，变更由 Git 与关联 PR 追踪；Issue 记录认领、讨论和验收状态。
