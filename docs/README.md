## 项目与部署

- [项目说明](../README.md)：环境要求、启动、构建与主要功能。
- [部署说明](../deploy/README.md)：镜像构建和服务部署。
- [最新部署记录](../deploy/deployment-2026-10-27.md)：本次仅后端更新、备份和验证。
- [历史部署记录](../deploy/deployment-2026-10-20.md)：首次服务器配置与上线信息。

源码分别位于根目录 `src/` 和 `frontend/`；运维工具位于 `scripts/`，部署文件位于 `deploy/`，覆盖率产物位于 `reports/`。根目录三份 Excel 是初始化与测试的数据源，保留原位。

新增正式文档放入 `课程设计/`，图放入其 `图表/` 子目录；原型、测试说明和待实施方案分别放入对应目录，并更新本页入口。测试产物继续放在 `reports/`，避免复制到文档目录。
