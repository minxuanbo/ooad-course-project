# RBAC按钮统一置灰（2026-11-24，未部署）

基点为main的`3b0ec0a6db4aca591918a8c3b6b4185f537ebc23`。用户确认已进入菜单后，无权限按钮统一保留并置灰；暂不部署，留待晚上统一发布。本轮独立分支`codex/disabled-permission-actions`，不因修改或推送自动合入main、更新镜像或重启线上服务。

后续状态：用户于同日晚追加部署授权，按钮置灰已与应用管理一并发布；正式验证单独见[应用管理发布](application-management-release-20261124.md)。以下保留本轮修改时的离线验证与授权边界。

## 行为与边界

- 人员页的角色读取、调动与停用；部门及总览页查看员工；角色页新建、查看成员/权限、编辑与启停；资源页分类、属性编辑、映射读取和API启停，均按现有实际能力及对象限制使用原生disabled，不因无权而移除按钮。
- 统一灰色文字/背景及禁用光标，无权按钮不能打开弹窗或触发查询/写入；有权操作继续使用原流程。人员不可维护、账号已停用、部门不可增改删、部门角色定义资格均按原限制执行。
- 已保存集合可独立只读查看，移除、候选查询和保存保留置灰；不读取无权候选，不把未读取候选写成真实零条；锁定角色保留且不可移除。关闭/取消仍可用，写请求403后沿原流程刷新身份、禁用失效操作并保留错误。
- 左侧菜单、总览快捷导航及路由准入不变，不自动授予父权限或任何读取/写入能力。老师课程前端、后端、OpenAPI、SQL及真实业务数据无改动；Apifox契约不变，本轮没有写入Apifox。
