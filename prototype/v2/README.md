# 新交互原型 · 第一轮

2026-11-13，分支codex/interactive-prototype，起点b78a6bf（PR #30）。本轮为用户已确认的阶段3第一轮；尚未通过用户界面审核，不是正式前端实现或真实API验收。

## 打开

用Edge、Chrome或其他现代浏览器**直接双击[index.html](index.html)**。无需安装依赖、构建、启动服务、登录真实账号或连接后端。index.html加载同目录普通脚本model.js/app.js和styles.css；把这四个文件放在同一文件夹即可离线运行，不使用ES Module、fetch、远程字体/CDN或浏览器存储。刷新即还原数据。

登录页点击演示身份自动填入，再点“登录”。所有演示账号共用虚构口令Demo@2026，不能作为生产凭据。

| 演示身份 | 账号 | 管理范围 |
| --- | --- | --- |
| 系统管理员 | admin | 总公司及全部下级 |
| 公司领导 | SG000001或13800000001 | 第一分公司及下级 |
| 部门经理 | SG000002 | 总公司工程管理部及下级 |
| 项目经理 | SG000003 | 滨江项目部 |
| 普通员工 | SG000004 | 拒绝进入管理端 |

所有人名、工号、手机号、168名人员和15个示例组织均为虚构交互数据，不使用原Excel真实人员，不代表正式初始化的10001账号/110部门。额外协同角色只用于演示候选分页，不改变正式五角色初始化规则。

## 本轮覆盖

- 浅色蓝色企业后台，左侧导航、顶部身份及组织人员工作区；电脑端为主，兼顾窄屏。
- 登录错误、普通员工准入拒绝、工号/手机号同身份、密码显示/隐藏、退出。
- 部门树展开/折叠及本地搜索；人员姓名/工号、状态、部门组合筛选、分页、空结果、刷新。
- 当前完整角色读取，受限候选分页/搜索、跨页已选草稿、取消/放弃修改、清空确认、整体保存、失败保留草稿。
- 人员信息只读；停用确认与调动双范围确认；不增加人员新增/删除/恢复按钮。
- 同账号撤权后的下一请求拒绝、本人保护、最后完整维护者409回滚的内存演示。
- 加载、重复写入保护、键盘焦点及原生模态框；身份切换时丢弃旧请求。

本轮导航只出现已制作的部门人员页面。角色定义、资源/API映射、鉴权日志是后续原型轮次，并未从整个项目范围删除。

## 建议审核顺序

1. 看登录页和默认工作台的颜色、布局、字号及信息密度。
2. 选不同部门，搜索工号/姓名，筛选停用状态并翻页。
3. 对沈清禾（SG000004）打开“分配角色”，跨候选页勾选，取消后确认放弃，再打开核对未保存；随后重新勾选并保存。
4. 对宋亦宁（SG000006）检查已停用角色完整显示，需明确移除才能再次保存。
5. 人员“更多”菜单尝试调动、停用；对admin尝试撤去管理员角色、停用或调出共同根，观察保护错误和未保存草稿。
6. “原型评审”切换公司领导/部门经理/项目经理，看可见组织和本人保护；普通员工演示管理准入拒绝。
7. 评审工具选择409/网络故障及“下一次保存”，再进行写操作，观察失败后草稿；选择“下一次任意请求”可检查读取失败/401。
8. 非最后维护者身份下模拟撤权，再刷新列表；重置数据返回登录页。

“原型评审”是单独的演示工具，不拟放入正式产品。模拟requestId以demo-开头；响应延迟、错误及保护均为浏览器内存行为，不是后端事务、锁或安全保证。

## 页面与现有API边界

| 页面动作 | 后续真实接口 |
| --- | --- |
| 登录、本人、退出 | POST /api/auth/login、GET /api/me、GET /api/me/permissions、POST /api/auth/logout |
| 部门树与人员列表 | GET /api/departments/tree、GET /api/users |
| 人员信息中的当前角色、分配抽屉 | GET /api/users/{id}/roles |
| 候选分页/搜索 | GET /api/users/{id}/assignable-roles |
| 整体角色保存 | PUT /api/users/{id}/roles |
| 停用、调动 | PATCH /api/users/{id}/status、PUT /api/users/{id}/department |

人员列表沿现有UserVO只显示基本字段，不为表格每行提前查询角色；打开抽屉才独立读取完整角色。已选标签由当前集合与访问过的候选页维护，不通过全局角色目录或全量候选重建。页面操作依据可用能力和范围，不按角色名硬判；正式前端获准操作的发现仍沿已有设计的查询/受控预检，不新增资格接口。本轮不修改OpenAPI或后端。

```text
node --check prototype/v2/model.js
node --check prototype/v2/app.js
node --test prototype/v2/tests/*.test.cjs
```
