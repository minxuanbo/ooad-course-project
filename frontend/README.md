# Vue正式管理前端

Vue3、vue-router与Vite。包含登录、总览、部门、人员、角色、资源与鉴权日志七个工作区，全部通过真实RBAC接口读取和提交，不包含原型内存模型、模拟故障开关或其他业务系统的演示页面。

完整新库、初始化、分支与双终端步骤见[组员复现指南](../docs/reproduction.md)。后端默认8081，开发前端默认5173；本README中的命令需要先准备真实后端。

在本目录运行：

```powershell
npm ci
npm test
npm run build
# 默认代理后端8081；本地联调可指定实际地址
$env:API_TARGET='http://127.0.0.1:8081'
npm run dev
```

开发服务仅监听127.0.0.1。服务器使用Nginx容器，配置与当前发布状态见[部署指南](../deploy/README.md)。离线原型仍可直接打开[prototype/index.html](../prototype/index.html)，与需要真实后端的正式Vue页面分开。

api.js统一管理Bearer、信封、401及身份变更。GET /me提供最新实际路由与可信根范围，入口不按角色名称猜测，也不通过额外日志请求探测权限。页面的显示限制不替代后端逐请求鉴权。

每次导航仅一次GET /me，不串行请求未使用的权限明细；登录也不在导航前重复刷新。人员页翻页/筛选复用当前页有效部门树，“刷新部门”重读最新身份和树；范围变化及失败关闭旧选项。总览活动失败只提示该区域，可单独重试，不阻塞主统计。交互规则见[前端设计](../docs/frontend-design.md)。

Modal负责原生dialog焦点约束；Pagination负责数据库分页；CollectionEditor独立保存完整已选集合与当前候选页。初读失败禁保存，完整重试不丢已选，候选失败可重试；删除和停用使用页面内确认。日志页筛选与每批条数绑定同一查询快照，在途改条件后不能续旧游标。

自动检查包括响应信封、入口能力、初读失败、重试、关闭晚响应、部门树搜索及日志竞态；离线原型用例只证明原型行为。`npm run test:e2e`需显式启用和专用虚构夹具，不自动启动后端或重置数据库。两策略浏览器、前端测试及构建的实际成绩见[验收入口](../docs/testing-acceptance.md)。

管理请求使用Bearer携带HS256身份JWT；角色权限由后端逐请求重算。日志页面、详情和总览活动统一以Asia/Shanghai显示北京时间，筛选显式转UTC提交，不依赖浏览器时区；该修正的待发布状态亦见验收入口。
