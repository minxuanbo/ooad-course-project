# Vue正式管理前端

Vue3、vue-router与Vite。包含登录、总览、部门、人员、角色、资源与鉴权日志七个工作区，全部通过真实RBAC接口读取和提交，不包含原型内存模型、模拟故障开关或其他业务系统的演示页面。

在本目录运行：

```powershell
npm ci
npm test
npm run build
# 默认代理后端8081；本地联调可指定实际地址
$env:API_TARGET='http://127.0.0.1:8081'
npm run dev
```

开发服务仅监听127.0.0.1。正式部署方案等待服务器要求，本阶段不操作服务器。离线原型仍可直接打开[prototype/index.html](../prototype/index.html)，与需要真实后端的正式Vue页面分开。

api.js统一管理Bearer、信封、401及身份变更。GET /me提供最新实际路由与可信根范围，入口不按角色名称猜测，也不通过额外日志请求探测权限。页面的显示限制不替代后端逐请求鉴权。

Modal负责原生dialog焦点约束；Pagination负责数据库分页；CollectionEditor独立保存完整已选集合与当前候选页。初读失败禁保存，完整重试不丢已选，候选失败可重试；删除和停用使用页面内确认。日志页筛选与每批条数绑定同一查询快照，在途改条件后不能续旧游标。

自动检查包括响应信封、入口能力、初读失败、重试、关闭晚响应、部门树搜索及日志竞态；测试中的离线原型用例仅证明原型行为，不代替正式后端或浏览器验收。后端及界面本轮实际证据见[阶段4验收](../docs/acceptance/stage4-vue.md)。
